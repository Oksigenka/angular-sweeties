# 🍰 Sweeties — Online Bakery
 
> An Angular app for a bakery featuring a dessert menu, a dessert builder, and online ordering.
 
## Demo
 
🌐 **Live Demo:** [https://oksigenka.github.io/angular-sweeties/](https://oksigenka.github.io/angular-sweeties/)
 
---
 
## About the Project
 
**Sweeties** — is a modern web app for bakeries that lets you browse dessert menus, create your own treats, read customer reviews, and place orders online.
 
---
 
## Features
 
### 🍩 Dessert Menu
- A catalog of all the pastry shop’s desserts
- A detailed page for each dessert, including a description, ingredients, and calorie count
### 🎨 Dessert Builder
- A step-by-step interactive builder for creating your own dessert
- At each step, you can choose the base, filling, topping, and other options
### 🏪 About Us
- Information about the pastry shop: history, values, team
### 📍 Contact
- Address, phone number, email, and contact form
### ⭐ Reviews
- Customer reviews of desserts and service
### 🛒 Cart and Payment
- Adding desserts to the cart
- Viewing and editing your order
- Order checkout and payment page

## Installation and Setup
 
### Requirements
- Node.js >= 18
- npm >= 9
### Steps
 
```bash
# 1. Clone the repository
git clone https://github.com/oksigenka/angular-sweeties.git
cd angular-sweeties
 
# 2. Install dependencies
npm install
 
# 3. Start the local server
npm start
```
 
Open in your browser: [http://localhost:4200](http://localhost:4200)
 
### Production build
 
```bash
npm run build
```
